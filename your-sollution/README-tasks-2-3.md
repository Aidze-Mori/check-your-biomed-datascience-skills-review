## Запуск

Из корня репозитория, Python 3.12:

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -r your-sollution/requirements-tasks-2-3.txt
.venv/bin/python your-sollution/task2_1_solution.py
.venv/bin/python your-sollution/task2_2_solution.py
.venv/bin/python your-sollution/task3_1_solution.py
.venv/bin/python your-sollution/task3_2_solution.py
```

В notebook выберите интерпретатор этого окружения и выполните все ячейки
по порядку. Источник данных — локальная папка `dataset`.

## Ограничения результатов

В 2.1 редкий класс 4 не распознан: все три его примера внутреннего теста
отнесены к классу 0. Поэтому общая Accuracy не описывает качество всех классов.

В 2.2 и 3.2 метки читаются только после фиксации метода и внешних назначений.
ARI и NMI не участвуют в выборе метода. В 3.2 silhouette считается на
фиксированной подвыборке из 1000 изображений; при сравнении разных
представлений это характеристика компактности, а не доказательство
правильной классификации тканей.

Данные PPG содержат внешние окна тех же людей. Для изображений нет ID пациентов.
Результаты не являются проверкой диагностики на независимых пациентах.

## Повторение прогнозов

Скрипты используют `seed=42`; CNN работают на CPU с двумя потоками.
Сохранены веса сетей и параметры предобработки. Для загрузки весов
используется `torch.load(..., weights_only=True)`.
Версии библиотек закреплены в `requirements-tasks-2-3.txt`.
На другой платформе возможны небольшие численные отличия.

Исходные `dataset` и `vanilla-code` не изменены. Для отмены любого задания
можно отменить соответствующий коммит: данные других заданий это не затронет.
