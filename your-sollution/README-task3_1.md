# Задание 3.1 — Классификация изображений тканей

Королев Даниил, группа 636-02.

Обучил CNN с тремя свёрточными блоками на 32/64/128 каналов. Пиксели преобразованы в [-1,1] через среднее и STD 0.5. Использовал отражения, веса классов, BatchNorm и Dropout. Разбиение 5040/1080/1080; выбрана эпоха 38 по macro F1 валидации.

## Запуск

Python 3.12. Из корня репозитория:

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -r your-sollution/requirements-tasks-2-3.txt
.venv/bin/python your-sollution/task3_1_solution.py
```

Для notebook откройте `task3_1_solution.ipynb`, выберите это окружение
и выполните все ячейки по порядку. Рабочая папка — корень репозитория
или `your-sollution`. Используются локальные данные; скачивать набор заново не нужно.
