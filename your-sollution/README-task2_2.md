# Задание 2.2 — Кластеризация PPG

Королев Даниил, группа 636-02.

Из каждого восьмисекундного окна извлёк 13 амплитудных, спектральных и пульсовых признаков. Основным заранее выбрал нормализацию внутри испытуемого, затем PCA8 и KMeans с тремя кластерами. Общая нормализация оставлена для сравнения.

## Запуск

Python 3.12. Из корня репозитория:

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -r your-sollution/requirements-tasks-2-3.txt
.venv/bin/python your-sollution/task2_2_solution.py
```

Для notebook откройте `task2_2_solution.ipynb`, выберите это окружение
и выполните все ячейки по порядку. Рабочая папка — корень репозитория
или `your-sollution`. Используются локальные данные; скачивать набор заново не нужно.

## Результат

На 48 обучающих окнах ARI 0.239, NMI 0.258, silhouette 0.173. Метки активности прочитаны после фиксации метода и внешних назначений. Внешние окна принадлежат тем же восьми людям; перенос на новых испытуемых не проверен.

В `outputs/task2_2_predictions.csv` сохранены 24 строки
с исходными ID. Графики, метрики, параметры модели и сведения о запуске
находятся в `outputs/task2_2_analysis`. Отчёт — `task2_2_report.md`,
1351 знак. Прогнозы из notebook совпали с запуском Python-скрипта.

Исходные данные и примеры `vanilla-code` не менялись.
