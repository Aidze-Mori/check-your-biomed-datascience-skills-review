# Задание 2.1 — Классификация ЭКГ

Королев Даниил, группа 636-02.

По 140 отсчётам сокращения обучил 1D CNN различать пять классов. StandardScaler и веса классов рассчитаны по обучению. Разбиение 2800/600/600, эпоха выбирается по macro F1 валидации.

## Запуск

Python 3.12. Из корня репозитория:

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -r your-sollution/requirements-tasks-2-3.txt
.venv/bin/python your-sollution/task2_1_solution.py
```

Для notebook откройте `task2_1_solution.ipynb`, выберите это окружение
и выполните все ячейки по порядку. Рабочая папка — корень репозитория
или `your-sollution`. Используются локальные данные; скачивать набор заново не нужно.

## Результат

На внутреннем тесте Accuracy 0.913, macro F1 0.582. Все три примера редкого класса 4 отнесены к классу 0. Поэтому одной общей Accuracy здесь недостаточно.

В `outputs/task2_1_predictions.csv` сохранено 1000 строк
с исходными ID. Графики, метрики, параметры модели и сведения о запуске
находятся в `outputs/task2_1_analysis`. Отчёт — `task2_1_report.md`,
1330 знаков. Прогнозы из notebook совпали с запуском Python-скрипта.

Исходные данные и примеры `vanilla-code` не менялись.
