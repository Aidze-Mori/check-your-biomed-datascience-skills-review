# Задание 3.2 — Кластеризация изображений тканей

Королев Даниил, группа 636-02.

Сравнил PCA50 по пикселям с 92 признаками цвета и текстуры, StandardScaler и PCA95%. В обоих вариантах KMeans с девятью кластерами. Представление выбрано по silhouette на фиксированной случайной подвыборке из 1000 изображений, без меток тканей.

## Запуск

Python 3.12. Из корня репозитория:

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -r your-sollution/requirements-tasks-2-3.txt
.venv/bin/python your-sollution/task3_2_solution.py
```

Для notebook откройте `task3_2_solution.ipynb`, выберите это окружение
и выполните все ячейки по порядку. Рабочая папка — корень репозитория
или `your-sollution`. Используются локальные данные; скачивать набор заново не нужно.

## Результат

Выбраны цвет и текстура, 21 компонента PCA. ARI 0.188, NMI 0.333, silhouette 0.220. Метки открыты после фиксации метода и внешних назначений. Кластеры не равны типам ткани, их размеры различаются: самый маленький содержит четыре изображения.

В `outputs/task3_2_predictions.csv` сохранено 900 строк
с исходными ID. Графики, метрики, параметры модели и сведения о запуске
находятся в `outputs/task3_2_analysis`. Отчёт — `task3_2_report.md`,
1489 знаков. Прогнозы из notebook совпали с запуском Python-скрипта.

Исходные данные и примеры `vanilla-code` не менялись.
